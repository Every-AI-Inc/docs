## Overview

This page lists every tool that the Every admin MCP server (`https://admin-mcp.every.ai`) gives to an MCP client that is not ChatGPT or Claude. ChatGPT and Claude get a reviewed subset of the same tools. The list is generated from the live server, so the names, inputs and classifications match what a client receives.

- **Transport:** Streamable HTTP at the root URL.
- **Authentication:** OAuth 2.1 through Clerk (dynamic client registration, authorization code with PKCE, `offline_access` refresh), or an organization [API key](/integrations/api-keys) for headless use. Every tool acts only inside the signed-in member's organization.
- **Read-only access:** an API key can be limited to read permissions. An OAuth connection gets the member's normal permissions in Every.
- **Rate limits:** an API key is limited to 120 requests per minute by default. An admin can change this per key. OAuth connections use the member's normal plan limits. `ask_assistant` uses the organization's AI credits.

## How tools are classified

| Class | Meaning | What Every does |
|-|-|-|
| **Read** | Returns information. Changes no data, account state or permissions. | Runs at once. |
| **Write** | Creates or changes data inside Every. | The first call returns a short confirmation phrase. Call the same tool again with `confirmation` set to that phrase. |
| **Sensitive write** | Sends something to another person, deletes or voids a record, or changes what can happen automatically. | Tools marked "Approve in the Every app" wait until the member approves the exact action in Every. The call returns a pending result. After approval, repeat the same call with the same arguments before the approval expires. A changed argument creates a new request. Hosts should ask the user before every call to a sensitive write. |

Sends, deletes and voids are never done without approval. Every never moves money: `record_payment` records a payment that already happened, and invoices are paid outside the MCP connection.

## Results, errors and retries

- A tool that does not do what it was asked returns `isError: true` with `structuredContent.error = {code, message}`. Codes are stable. Examples: `not_found`, `invalid_request`, `reauthorization_required`.
- A pending approval, a denied approval or an expired approval is reported as an error that says that nothing changed.
- Tools that take an `operation_id` (a UUID that you choose) are safe to retry: repeat the same call with the same `operation_id` after an uncertain response, and the action runs at most once.
- Older argument names that were renamed are still accepted, but only the current names are advertised.
