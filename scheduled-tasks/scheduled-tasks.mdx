## Overview

Schedule agent work to run as a recurring routine or a one-time reminder. Instead of asking Every something each time, turn on the tasks you want it to keep doing — a morning brief, a sweep of overdue invoices, or any custom request — and Every runs them for you, on your schedule.

<Card title="Open Scheduled" icon="clock" href="https://app.every.ai/chat/scheduled" horizontal>
  Turn tasks on or off, set their cadence, and review past runs
</Card>

**Highlights:**
- Every run uses full agent context and posts its results to its own chat, with undo history
- Recurring tasks run on a cadence you choose — daily, weekly, monthly, or a custom interval — with timezone-aware start times
- One-time tasks run once, at a specific date and time
- Results show up in Activity on Home, plus an optional email summary
- One agent task runs at a time per workspace, so scheduled work never overlaps
- A manual **Run now** lets you test a task without touching its future schedule

<Note>
  Scheduled tasks were previously called "Heartbeat" / "Automations." The old `/agent/tasks`, `/agent/heartbeat`, and `/agent/automations` links now redirect to **Chat → Scheduled** at [https://app.every.ai/chat/scheduled](https://app.every.ai/chat/scheduled).
</Note>

## Recurring

Recurring tasks run on a repeating cadence you set. A built-in Daily Brief is always available, and you can add as many custom recurring tasks as you like.

### Built-in tasks

| Task | What it does |
|-|-|
| **Daily Brief** | Your "chief of staff" morning readout of what moved overnight and what needs your attention — see [Daily Brief](/scheduled-tasks/daily-brief). |

The built-in remains available in the task list. Turn each on or off and adjust its schedule and delivery. Existing Accounts Receivable Sweep tasks appear among your custom tasks; you can also create a custom task to review overdue invoices and draft reminders.

Automatic Network & Deals maintenance runs behind the scenes and is not a task you manage here. Manage Google discovery from your Google connection settings.

Prospecting is not a scheduled task. It runs automatically from the [Prospects](https://app.every.ai/prospects) page — see [Prospecting Agent](/prospecting/prospecting-agent).

### Custom recurring tasks

Write your own recurring request and Every runs it on the schedule you set — for example, "Every Monday, summarize last week's revenue and open proposals." Use **Add task**, describe the work, and pick a cadence.

## One-time

A one-time task runs once, at a specific date and time, then it's done — useful for a single reminder or a request you only need run once, like "Next Friday at 9am, check whether the ACME invoice was paid." Create one from **Add task** the same way as a custom recurring task, but choose a specific date and time instead of a repeating cadence.

## Creating a task

Use **Add task** from [Chat → Scheduled](https://app.every.ai/chat/scheduled) (or ask Every in a chat) to create a custom recurring or one-time task:

1. Describe the request in plain language.
2. **@-tag** specific people, companies, or deals to scope the task to them, or **@-tag an active [skill](/ai/memory-and-skills)** so the task follows that skill's guidance.
3. Choose **Recurring** (pick a cadence) or **One-time** (pick a date and time).
4. Save — Every runs it from here on.

<Tip>
  **Ask Every:** You can also set up a task conversationally — "Every weekday at 8am, check my inbox for unpaid invoices and draft reminders."
</Tip>

## Cadence & scheduling

Every recurring task stores a local run time, so it fires at the right moment for your timezone.

| Cadence | Behavior |
|-|-|
| **Daily** | Runs every day (or on chosen days of the week) at a set time. |
| **Weekly** | Runs on a chosen day of the week at a set time. |
| **Monthly** | Runs on a chosen day of the month at a set time. |
| **Custom interval** | Runs every _N_ hours or days. |
| **One-time** | Runs once at a specific date and time. |

<Note>
  Tasks that analyze history (like the Daily Brief) keep their lookback window in sync with cadence — a daily task reviews the last day, a weekly task the last week — so coverage doesn't overlap or leave gaps.
</Note>

## Managing tasks from chat

Ask Every in any chat to list your tasks, change a task's cadence or instructions, run one now, or turn it off. Active [skills](/ai/memory-and-skills) can also be @-tagged directly in chat, the same way you'd tag them when creating a task.

## Results, chats & undo

- **Its own chat.** Each run posts a summary, links, and any drafts into a dedicated chat. Open it from [Chat](https://app.every.ai/chat) to read the full result or follow up directly.
- **Undo history.** Runs that change records capture an undo snapshot, so you can revert a scheduled change right from the chat.
- **Activity.** Upcoming runs preview in **Activity** on [**Home**](https://app.every.ai/); completed runs show success or failure badges with quick links back to the originating chat.
- **Optional email.** Turn on the email summary for any task to also receive a recap by email after each run.

<Tip>
  Open a task and use **Run now** to validate a fresh setup on demand. A manual run uses the same executor as the schedule but leaves your future runs untouched.
</Tip>

## Good to know

<Warning>
  **One task at a time per workspace.** If you trigger a run while another agent task is already in flight, you'll see "Another agent task is running for this workspace" — wait for the current run to finish (check Activity on Home or the latest chat) before retrying.
</Warning>

- **Tasks use AI credits.** Each run consumes credits based on the work Every does. If your credits are exhausted when a run is due, it's skipped — see [Credit Usage & Errors](/plans/credit-usage-and-errors) for exactly what happens (including why a skipped run can show as "Completed").
- **Team scope.** In a multi-member workspace, your Daily Brief is private to you, while custom task definitions are shared with the team.
