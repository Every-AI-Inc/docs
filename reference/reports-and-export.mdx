## Download invoice summaries or expenses

1. Open [Ask Every](https://app.every.ai/threads) in the correct workspace.
2. Start a private conversation.
3. Ask for a CSV of active invoices or expenses. Include a date range if needed.
4. Open the download link from the same account and workspace.

```text
Download a CSV of active invoices issued from January 1 through March 31, 2026.
Download a CSV of active expenses dated from January 1 through March 31, 2026.
```

The invoice CSV has one summary row per invoice. It includes invoice dates, status, payment status, currency, and total. The expense CSV includes the date, merchant, category, description, currency, amount, and tax amount.

Each file uses one record type and includes only active records you can access. The date filter includes both dates. Each file has a limit of 5,000 records and 4 MiB. Ask for a shorter date range if the file exceeds either limit.

These CSVs contain workspace records. For a workbook or an edit to a CSV that you upload, describe that task separately in chat. The workspace CSV uses standard columns. Check the destination's field requirements before you import it into another system.

## Import records

1. Export a representative file as CSV or XLSX. Save older XLS files as XLSX first.
2. Attach the file in a private Ask Every conversation.
3. Tell Every which records to import.
4. Review the proposed fields and record matches. Confirm the import after you check the preview.
5. Check the receipt and verify a sample of the records in Every.

Keep the original file. For [LinkedIn](/network/people#linkedin-import) or [Google Contacts](/network/people#google-contacts-import), use the source controls in People.

### Find an import receipt

Open [Inbox](https://app.every.ai/activity). In **Activity**, select **Import history** and open the receipt. You can also find a receipt in its original private conversation if you still have access to that conversation.

The receipt shows available counts and results. If the receipt offers **Undo**, review the changes before you confirm. Undo can retain records that changed after the import. A queued Undo updates the receipt when it finishes.

Receipt access depends on your role and the import. Import history does not restore erased conversations or deleted source files.

## Ask a financial question

Ask Every about the financial records you can access.

- “Which invoices are overdue?”
- “What were my expenses by category last month?”

[Connected AI tools](/integrations/connect-ai-tools) can also use the Every MCP financial summary, subject to workspace access.

## Request other workspace data

For other workspace data, such as time records, contact [hello@every.ai](mailto:hello@every.ai). Use this contact if you cannot sign in or if your subscription ended. Include the workspace name, requested records, and date range. Every verifies your authority for the workspace. After approval, Every delivers only the agreed records through a private channel.
